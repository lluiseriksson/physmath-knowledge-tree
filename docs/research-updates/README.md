## Five starting points

1. **Zeta kernels and moment certificates.** [Lamzouri v2](https://arxiv.org/abs/2609.02882v2) adds union/average proportion estimates; [Wang](https://arxiv.org/abs/2609.07918v1) localizes the method to short intervals. Compare their kernel quantifiers with the one-point Stieltjes criterion without assuming RH.
2. **SDP limits and restricted recovery.** Compare [HNW-model lower bounds](https://arxiv.org/abs/2609.09033v1) with the stronger concurrent [no-disentangler result](https://arxiv.org/abs/2609.02865v1). Universal state coverage and one code-restricted recovery map have different quantifiers.
3. **Tree gauge coordinates and reflection.** The [maximal-tree simulation framework](https://arxiv.org/abs/2608.27267v1) is a useful August precursor for the concrete edge-coordinate frontier in the 2D satellite. The next test is a map/inverse and face-holonomy calculation with product Haar retained.
4. **Explicit Hodge classes and prescribed detectors.** [Split-binary matrix factorizations](https://arxiv.org/abs/2609.03784v1) give a family-specific positive control. Test the map to the required Saito pairing before using these classes in the general Hodge research front.
5. **Experimental resets and maintenance bounds.** [Ancilla reservoir engineering](https://arxiv.org/abs/2609.04905v1) and [open SU(2) dynamics](https://arxiv.org/abs/2609.04117v1) motivate finite control-class and Zeno checks for the leakage papers. Reset work and Davies assumptions remain explicit.
