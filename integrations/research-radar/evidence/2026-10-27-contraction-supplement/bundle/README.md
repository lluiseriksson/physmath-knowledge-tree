# Bounded contraction proof controls

Five fixed mathematical checkers support inspection of the combined contraction manuscript. This package is not a discovery optimizer, formal proof, originality certificate, independently certified computational campaign or manuscript assessment.

1. Copy this directory to a local working location.
2. Use Python3.10or newer and install `python -m pip install -r requirements.txt` in your environment. Tested dependency: SymPy1.14.0.
3. Run `python replay.py --workdir ./runs --out ./receipt.json`.

The runner verifies every listed payload, makes a fresh owned subdirectory, copies only the five programs there, and compares all JSON values against the frozen expected results. It preserves every stdout, stderr, failed attempt and output. It does not delete runs or write to any original C/D research dossier. Execution is local; no network or paid model service is used by replay.py or the five programs. Dependency installation is a separate user action.

- pauli-ladder.py:20exact symbolic projector, channel-block, Sylvester and harmonic identities. Analytic faithful limits are separate proof steps.
- doeblin-certificate.py: rational primal/dual and Bloch checks for a localized printed Theorem5 discrepancy. No judgment about the whole source article.
- near-nine-certificate.py: exact finite SLD witness near the antipolarizing endpoint. This certificate does not prove the universal factor9upper and does not assign a score.
- ranktwo-profile.py: symbolic-d aligned-plane identities, full matrices in dimensions2/3/4 and4rational faithful finite-pair controls for the proposed larger order range. These checks alone are not an external review or a proof of all quantifiers.
- bell-budget.py:6rational controls for the Bell order-budget family, including qubit PPT pairs. The all-generator assertion rests on the analytic Taylor limit, not sampling generators.

ORIGINS1027 records original script hashes, exact transport/projection hashes and the one portability transformation. For bell-budget.py only archival hashing/copying code and an unused absolute-path assignment were removed; its mathematical output is unchanged. Embedded result fields such as external_review:null and pending-review comments are historical original outputs; actual current audit status belongs to the accompanying reports, not an edited expected result. No earlier manuscript grade applies to this package or a later PDF. No third-party paper full text or private submission PDF is included.

Keep the context distinction: model-assisted audits can reuse conversational context and a shared filesystem; they are not independent human peer review or formal verification. The exact manuscript must have its own assessment, objections and PDF hash.
